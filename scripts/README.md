# Scripts

| Script | Purpose |
|--------|---------|
| `run_lab.sh` | Runs `ping` and `traceroute` for Parts 1 and 2 and saves timestamped output into `outputs/`. |

Read the script before running it. It only uses `ping`, `traceroute`, `date` and `mkdir`. The lab still expects you to type and understand the commands yourself, so use the script to save time on documentation, not to skip learning.
